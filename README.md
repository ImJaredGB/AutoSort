Auto Sort 📁
---------------
Auto Sort es una aplicación de código abierto desarrollada en Python por Aale, diseñada para automatizar la organización de archivos en la carpeta de Descargas.

Su objetivo es mantener la carpeta de Descargas organizada de forma automática, clasificando los archivos según su extensión y creando las carpetas correspondientes cuando sea necesario.

  Auto Sort está desarrollado para uso personal y educativo.
  No se permite su uso para distribuirse con fines de lucro.
  
？Como funciona
---------------
Auto Sort trabaja directamente sobre la carpeta predeterminada de Descargas del sistema:

_macOS:_ ~/Downloads

_Windows:_ Downloads

Una vez activada la automatización, la aplicación supervisa la carpeta de Descargas y, cuando detecta nuevos archivos, los organiza automáticamente.

*Importante:* cerrar la ventana no equivale necesariamente a detener la automatización. Para detener el proceso, desactiva primero el interruptor de ordenación.

🔒 Privacidad
---------------

Auto Sort está diseñado para realizar su funcionamiento localmente en el equipo del usuario.

La aplicación no necesita enviar los archivos organizados a servidores externos para realizar su función.

Como con cualquier software descargado desde Internet, se recomienda obtener Auto Sort únicamente desde los repositorios y publicaciones oficiales del proyecto.
